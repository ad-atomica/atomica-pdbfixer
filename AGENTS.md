# Contributing to this fork

- **MUST** make minimal changes to keep this fork as close to upstream PDBFixer as possible.
- **MUST** submit each minimal fix in its own pull request.
- **MUST** keep each fix in a single commit.
- **MUST** use the standard template for a report under `docs/`. Describe and justify each commit, state the intended behavior, and explain how to reimplement and verify the change after an upstream PDBFixer update. [Report template](docs/REPORT_TEMPLATE.md)
